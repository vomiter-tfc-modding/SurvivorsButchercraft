# Survivor's Butchery

Survivor's Butchery is a compatibility mod that integrates **TerraFirmaCraft** with **Butchercraft**.

It integrates Butchercraft's butchering mechanics into TerraFirmaCraft's metal progression, animal yield, and food decay systems while providing a more complete carcass-processing experience for certain domesticated animals.

## Required Mods

*   TerraFirmaCraft
*   Butchercraft
*   Survivor's Abilities 1.5+

JEI is highly recommended for viewing butchering tool requirements and recipes.

# Main Features

## Scope of the Butchering Process

Only certain domesticated animals can be converted into carcasses using a butcher knife.

Currently supported animals include:

*   Pig
*   Cow
*   Sheep
*   Goat
*   Yak
*   Musk Ox

Animals killed without using a butcher knife will retain their normal TerraFirmaCraft drops.

## Multi-Stage Butchering

Using a butcher knife on an eligible domesticated animal produces a carcass, which can then be hung on a meat hook and processed through five stages:

1.  Drain Blood
2.  Skinning
3.  Beheading
4.  Gutting
5.  Butchering

Each stage requires specific tools and yields different cuts and by-products.

## Metal Tools and Meat Hooks

Butchering tools and meat hooks are fully integrated into TerraFirmaCraft's metal progression.

Multiple metal variants are available, allowing players to craft and use equipment appropriate for their current technological stage.

## Tool Compatibility

Each processing stage has a recommended tool.

Several TerraFirmaCraft tools, such as knives, axes, saws, and shears, can also be used as alternatives. However, using alternative tools may reduce yields or increase tool durability consumption.

## JEI Integration and HUD Hints

JEI integration allows players to view the required tools for each butchering stage.

Simple on-screen hints are also provided to indicate the recommended tool and available alternatives while interacting with a carcass.

## Animal Yield Integration

Carcass drops are scaled according to TerraFirmaCraft's animal yield system, so that familiarity and genetic size would affect final drops.

## Blood Collection with Fluid Containers

Blood can be collected during the draining stage using any container that supports the Forge Fluid Capability.

This includes TerraFirmaCraft's wooden bucket and colored steel buckets, allowing them to be used in place of Butchercraft's default iron bucket.

## Food Decay Integration

Carcasses and their products are affected by TerraFirmaCraft's food decay system.

Unprocessed carcasses spoil quickly, encouraging players to process and preserve their products promptly. Spoiled carcass on meat hook would be rendered with a greenish tint.

## Mod Compatibility
1. Pig carcass drops ham in the butchering stage.
2. Gutting certain animals provide firmalife rennet.
3. Gutting certain animals provide waterflask bladder.

# Basic Gameplay

1.  Craft a butcher knife and a meat hook.
2.  Use the butcher knife on an eligible domesticated animal.
3.  Hang the carcass on the meat hook.
4.  Complete each processing stage in order.
5.  Preserve or further process the resulting products.

Animals that are not butchered through this system will continue to drop their normal TerraFirmaCraft loot.
